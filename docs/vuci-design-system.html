02 · Type scale

Big ideas, quiet detail.

Use a wide, expressive grotesk for promises and narrative. Use a calm sans for everything the user must scan. Mono is reserved for timestamps, provenance, API names, and system metadata.

04 · Motion gallery

Motion should explain state.

Hover is fast. State change is normal. Panels enter slowly enough to read as a new layer. Spring is reserved for a successful save or a result landing. Reduced-motion collapses the full system to 1ms.

Fast · 120ms

Why: confirms hover or focus.

Normal · 220ms

Why: changes a local state.

Slow · 360ms

Why: introduces a new layer.

Slower · 520ms

Why: hero or AI response.

Spring · reserved

Why: a saved moment lands.

05 · Liquid glass

Use depth only when depth is true.

Glass is for navigation, overlays, and generated intelligence that visibly sits above source material. Editorial reading surfaces stay opaque. Never put glass on glass.

Subtle · 10% / 8px

Context nav

For pinned bars and quiet controls over a low-contrast canvas.

Standard · 22% / 22px

Floating tools

For menus, inspectors, and source panels above content.

Hero · 35% / 40px

One signature layer

For the AI synthesis surface or a single feature announcement.

06 · AI-ambient surface

Separate input from inference.

User input is solid and crisp. Generated output is frosted, source-linked, reversible, and explainable. This keeps the intelligence feeling ambient without hiding where it came from.

08 · Page families

Four templates cover the product.

The Vuci study resolves into four page archetypes. Build these as composable templates before designing one-off pages. New screens should be a variation of one family, not a new language.

Marketing

Every source, finally useful.

Oversized promise, short proof, then live product fragments—not device mockups.

A · Editorial marketing

For homepage, pricing, developers, and audience landing pages. 102px desktop / 44px mobile hero type, 110px section rhythm, demonstrative components in every section.

B · Product discovery shell

For feed, search, spaces, groups, and alerts. 72px desktop rail hidden below 768px, edge-to-edge mobile content, mixed-density cards, persistent bottom action only when necessary.

1127 episodes

Modern conversations

C · Source / episode detail

For podcast, episode, person, or single insight. Immersive dark source header with a 64px lower arc, then a narrow reader containing summary, glossary, chapters, citations, and related cards.

Research report · 8 min

What the market is saying.

D · Research report

For synthesized intelligence. 912px reading column, 64px title, compact metric exhibits, paired “for / against” argument blocks, sticky contents, and source attribution next to each claim.

09 · Depth / spatial

Layer by meaning, not decoration.

Base content remains flat. A raised card means “grouped.” A floating control means “available in context.” A modal means “decision required.” Pair each z-layer with one elevation token.
